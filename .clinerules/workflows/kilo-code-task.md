# Kilo Code Task Workflow

Standardized workflow for tasks handled by Kilo Code AI assistant.

## Trigger
- Any task assigned to Kilo Code
- Complex multi-step operations
- Code changes, debugging, or analysis tasks

## Priority
High

## Estimated Duration
Varies by task complexity

## Phases

### 1. Analysis Phase
Understand the task requirements and context.

- [ ] Read relevant files and understand codebase structure
- [ ] Analyze requirements and acceptance criteria
- [ ] Check applicable rules from .clinerules
- [ ] Determine appropriate mode (architect, code, ask, debug, orchestrator)
- [ ] Assess if MCP servers are needed

### 2. Planning Phase
Create a structured plan for execution.

- [ ] Break down task into clear, achievable steps
- [ ] Create todo list for complex tasks
- [ ] Identify required tools and resources
- [ ] Consider DDD architecture and SOLID principles
- [ ] Plan for testing and validation

### 3. Execution Phase
Implement the solution following best practices.

- [ ] Execute steps iteratively using appropriate tools
- [ ] Apply relevant clean code rules
- [ ] Maintain code quality standards
- [ ] Use MCP servers when beneficial
- [ ] Document decisions and rationale

### 4. Validation Phase
Verify the implementation meets requirements.

- [ ] Test changes thoroughly
- [ ] Ensure adherence to rules and standards
- [ ] Validate against acceptance criteria
- [ ] Check for security and performance issues

### 5. Completion Phase
Finalize and document the work.

- [ ] Update documentation if needed
- [ ] Clean up temporary files or artifacts
- [ ] Confirm all requirements are met
- [ ] Provide summary of changes

## Rules
- Always follow the pre-prompt rules for the active mode
- Use appropriate tools efficiently
- Maintain clear communication
- Ensure changes align with project architecture
- Test all modifications

## Checkpoints
- [ ] Task requirements understood
- [ ] Appropriate mode selected
- [ ] Plan created and approved
- [ ] Implementation completed
- [ ] Validation passed
- [ ] Documentation updated
