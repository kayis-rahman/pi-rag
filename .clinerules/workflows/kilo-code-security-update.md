# Kilo Code Security Update Workflow

Handle security vulnerabilities and updates using Kilo Code AI assistant.

## Trigger
- Security vulnerabilities detected
- Dependency security alerts
- Security audit findings

## Priority
Critical

## Estimated Duration
1-3 days

## Phases

### 1. Assessment Phase
Assess the security vulnerability.

- [ ] Vulnerability analysis and impact assessment
- [ ] Risk level determination (CVSS scoring)
- [ ] Affected component identification
- [ ] Code review for security issues

### 2. Planning Phase
Plan the security fix.

- [ ] Security fix strategy development
- [ ] Communication plan for stakeholders
- [ ] Rollback and contingency planning
- [ ] Timeline and priority assignment

### 3. Implementation Phase
Implement the security fix.

- [ ] Apply security fixes immediately
- [ ] Update vulnerable dependencies
- [ ] Implement security workarounds if needed
- [ ] Update security configurations and logging

### 4. Testing Phase
Comprehensive security testing.

- [ ] Security regression testing
- [ ] Penetration testing validation
- [ ] Compatibility and integration testing
- [ ] Performance impact assessment

### 5. Deployment Phase
Safe deployment of security fixes.

- [ ] Emergency deployment procedures
- [ ] Stakeholder communication
- [ ] Post-deployment monitoring
- [ ] Incident documentation and lessons learned

## Rules
- Security takes precedence over other concerns
- Minimal changes to reduce risk
- Immediate vulnerability patching
- Comprehensive security testing
- Emergency communication protocols
- Input validation and authentication updates
- MCP server usage: sonarlint, curl, memory

## Checkpoints
- [ ] Vulnerability confirmed and assessed
- [ ] Fix strategy approved
- [ ] Security testing completed
- [ ] Emergency rollback plan ready
- [ ] Stakeholder communication sent
