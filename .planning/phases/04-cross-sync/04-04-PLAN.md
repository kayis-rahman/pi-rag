<objective>
Implement sync failure exponential backoff with user-facing alert UI. After 3 consecutive sync failures, show a dismissible banner with manual retry.

Purpose: When sync repeatedly fails (network issues, auth expiration, backend downtime), the user should be notified rather than left unaware. The backoff intervals (30s → 60s → 120s → cap 300s) prevent aggressive retrying. The user alert gives control back to the user with a manual retry option.

Output: New SyncFailureAlertManager singleton, new SyncStatusBanner SwiftUI component, updated TimerSyncManager backoff logic, banner integrated into the app.
</objective>
