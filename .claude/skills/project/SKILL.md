# SKILL.md — Project Context Loader

Load a project's full context: goals, architecture, current phase, next steps.

## Read First
1. .obsidian/projects/[project-name]/README.md (if exists)
2. .obsidian/projects/[project-name]/STATE.md (if exists)
3. .planning/STATE.md (current phase)
4. clients/[client-name]/CONTEXT.md (if exists)
5. CLAUDE.md (project conventions)

## Project Context to Load
- Project goals and vision
- Architecture and tech stack
- Current phase and progress
- Next steps and blockers
- Active requirements from .planning/REQUIREMENTS.md

## Output
Full project context for Claude Code to use.
